# 骨架 D：管理后台（KPI + 多栏图表 + 列表表格）

> 来源参考：素材/6.png（管理后台大屏风格）
> 只描述排版结构，不含配色与文案。

## 适用场景

- 后台管理、列表驾驶舱、运营仪表盘、人员/任务监控。
- 适合"指标条 + 数据列表"组合，强调整体一览。

## 总体栅格

- **12 列** CSS Grid。
- 顶部 KPI 条 `120px`，中部图表分两行（2 栏 + 3 栏），底部为表格行。

## 槽位清单

| 槽位 ID           | 栅格坐标          | 必填字段                                  | 可选组件                |
|-------------------|-------------------|-------------------------------------------|-------------------------|
| `header-0`        | col 1–3 / row 1   | `title`, `value`, `unit`                  | KPI                    |
| `header-1`        | col 4–6 / row 1   | 同上                                      | KPI                    |
| `header-2`        | col 7–9 / row 1   | 同上                                      | KPI                    |
| `header-3`        | col 10–12 / row 1 | 同上                                      | KPI                    |
| `chart-2col-0`    | col 1–6 / row 2   | `title`, `x_field`, `y_field`, `data`      | 柱状 / 折线             |
| `chart-2col-1`    | col 7–12 / row 2  | 同上                                      | 折线 / 面积             |
| `chart-3col-0`    | col 1–4 / row 3   | 同上                                      | 饼图 / 环形             |
| `chart-3col-1`    | col 5–8 / row 3   | 同上                                      | 雷达 / 排行             |
| `chart-3col-2`    | col 9–12 / row 3  | 同上                                      | 柱状 / 漏斗             |
| `table-list`      | col 1–12 / row 4  | `columns[]`, `rows[][]`                   | 大列表表格              |

## 组件映射规则

1. KPI 数量应为 4，按业务重要性排 header-0..3。
2. `chart-2col-*` 留给"主时间序列对比"。
3. `chart-3col-*` 留给分布/构成类。
4. 表格必须独占最下方且行数 ≥ 10。

## 内容要求

- 顶部必须有 4 个 KPI（不能为 0）。
- 表格字段命名清晰。
- 总组件数 8–10 张图 + 1 张表。
