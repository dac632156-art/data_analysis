# 骨架 E：财务经营（KPI + 环形组 + 柱状 + 趋势）

> 来源参考：素材/9.png（财务/经营大屏风格）
> 只描述排版结构，不含配色与文案。

## 适用场景

- 财务指标、成本利润结构、KPI 完成率、营收结构。
- 适合带多个饼/环形 + 趋势对比。

## 总体栅格

- **12 列** CSS Grid。
- 顶部 KPI 条 `120px`，中部四等分（环形组），底部趋势行。

## 槽位清单

| 槽位 ID           | 栅格坐标          | 必填字段                                  | 可选组件                |
|-------------------|-------------------|-------------------------------------------|-------------------------|
| `header-0`        | col 1–3 / row 1   | `title`, `value`, `unit`, `target`        | KPI                    |
| `header-1`        | col 4–6 / row 1   | 同上                                      | KPI                    |
| `header-2`        | col 7–9 / row 1   | 同上                                      | KPI                    |
| `header-3`        | col 10–12 / row 1 | 同上                                      | KPI                    |
| `ring-0`          | col 1–3 / row 2   | `label`, `value`, `percent`               | 环形进度 / 占比         |
| `ring-1`          | col 4–6 / row 2   | 同上                                      | 环形进度 / 占比         |
| `ring-2`          | col 7–9 / row 2   | 同上                                      | 环形进度 / 占比         |
| `ring-3`          | col 10–12 / row 2 | 同上                                      | 环形进度 / 占比         |
| `bar-compare`     | col 1–8 / row 3   | `categories[]`, `series[]`               | 多系列柱状对比         |
| `trend-line`      | col 9–12 / row 3  | `title`, `x_field`, `y_field`, `data`      | 折线 / 面积             |
| `kpi-table`       | col 1–12 / row 4  | `columns[]`, `rows[][]`                   | KPI 汇总表              |

## 组件映射规则

1. KPI 选 4 个：营业收入 / 利润率 / 增长率 / 预算完成率。
2. 环形 4 个对应收入结构（按品类/区域/客户/产品）。
3. `bar-compare` 用于多维对比（如月度 vs 年度）。
4. `kpi-table` 行数 ≥ 12，覆盖至少 6 个月/部门。

## 内容要求

- 必须包含至少 3 张环形图。
- 表头含单位、百分比、同环比列。
- 总组件数 8–10 张图 + 1 张表。
