# 骨架 A：综合业务总览（KPI 条 + 三栏 + 底部趋势表）

> 来源参考：素材/1.png（营销大屏综合业务总览风格）
> 只描述排版结构，不含配色与文案。

## 适用场景

- 业务综合分析、用户总览、营销战役大盘、年度/季度汇总。
- 适合 8–12 张图表 + 多张表格的中等规模大屏。

## 总体栅格

- **12 列** CSS Grid。
- 顶部条高 `120px`，主区行高 `1fr`，底部条高 `1fr`。
- 主区采用 **三栏 4:4:4**，底部为 **双栏 6:6**。

## 槽位清单

| 槽位 ID        | 槽位区域 | 栅格坐标 (col / row)        | 必填字段                                                                                              | 可选组件                |
|----------------|----------|-----------------------------|-------------------------------------------------------------------------------------------------------|-------------------------|
| `header-0`     | header   | col 1–3 / row 1             | `title`, `value` (数字), `unit`, `trend` (同比/环比数组，可选)                                          | KPI 卡片                |
| `header-1`     | header   | col 4–6 / row 1             | 同上                                                                                                  | KPI 卡片                |
| `header-2`     | header   | col 7–9 / row 1             | 同上                                                                                                  | KPI 卡片                |
| `header-3`     | header   | col 10–12 / row 1           | 同上                                                                                                  | KPI 卡片                |
| `main-left`    | main     | col 1–4 / row 2             | `title`, `x_field`, `y_field`, `data` (≥5 条)                                                          | 柱状 / 排行 / 漏斗      |
| `main-center`  | main     | col 5–8 / row 2             | 同上                                                                                                  | 折线 / 面积 / 桑基      |
| `main-right`   | main     | col 9–12 / row 2            | 同上                                                                                                  | 饼图 / 环形 / 雷达      |
| `footer-left`  | footer   | col 1–6 / row 3             | `columns[]` (字段名), `rows[][]` (单元格数据), `total_rows`                                            | 表格                    |
| `footer-right` | footer   | col 7–12 / row 3            | 同上                                                                                                  | 洞察 / 文字型           |

## 组件到槽位的映射规则

1. **KPI 类（widget_type=KPI）** → `header-0..3` 顺序填充，最多 4 个；超过则把次要的降级为 main。
2. **柱状/排行/漏斗** → `main-left`。
3. **折线/面积/桑基** → `main-center`。
4. **饼图/环形/雷达** → `main-right`。
5. **表格/洞察** → `footer-left` → `footer-right`。

## 内容要求

- 顶部 KPI 至少 3 个，标题 ≤ 8 个汉字。
- 主区三栏必须填满，不能留空。
- 底部表格至少 1 张，行数 ≥ 5。
- 整体控制在 8–12 张组件。
