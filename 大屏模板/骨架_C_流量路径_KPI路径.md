# 骨架 C：流量路径分析（KPI + 桑基/路径 + 雷达 + 表格）

> 来源参考：素材/3.png（流量路径分析风格）
> 只描述排版结构，不含配色与文案。

## 适用场景

- 渠道转化、用户路径、漏斗分析、留存分析。
- 适合带桑基图/路径图/漏斗图的"流向"主题。

## 总体栅格

- **12 列** CSS Grid。
- 顶部 KPI 条 `120px`，主区分上下两行（每行 4 栏）。

## 槽位清单

| 槽位 ID           | 栅格坐标          | 必填字段                                  | 可选组件                |
|-------------------|-------------------|-------------------------------------------|-------------------------|
| `header-0`        | col 1–3 / row 1   | `title`, `value`, `unit`, `delta`         | KPI                    |
| `header-1`        | col 4–6 / row 1   | 同上                                      | KPI                    |
| `header-2`        | col 7–9 / row 1   | 同上                                      | KPI                    |
| `header-3`        | col 10–12 / row 1 | 同上                                      | KPI                    |
| `path-main`       | col 1–8 / row 2   | `nodes[]`, `links[]` (桑基源/汇)           | 桑基图 / 路径图         |
| `path-side`       | col 9–12 / row 2  | `title`, `x_field`, `y_field`, `data`      | 饼图 / 雷达 / 漏斗      |
| `trend-row-1`     | col 1–6 / row 3   | 同 path-side                              | 折线 / 面积             |
| `trend-row-2`     | col 7–12 / row 3  | 同 path-side                              | 柱状 / 排行             |
| `detail-table`    | col 1–12 / row 4  | `columns[]`, `rows[][]`                   | 大表格                  |

## 组件映射规则

1. KPI 全部放 `header-0..3`，按业务优先级排序。
2. 路径/桑基/漏斗 → `path-main`（必须，且最显眼）。
3. 雷达/饼图作为对照放 `path-side`。
4. 趋势图（折线/面积/柱状）按时间排序填充 `trend-row-*`。
5. 表格独占一行 `detail-table`，行数 ≥ 8。

## 内容要求

- 必须包含至少一张桑基图或漏斗图。
- 表格字段命名清晰（含时间/渠道/数量）。
- 适合 8–12 张组件 + 1 张大表。
