# 骨架 B：通用 BI（KPI 条 + 九宫格多图表）

> 来源参考：素材/2.png（BI 风多图表并置）
> 只描述排版结构，不含配色与文案。

## 适用场景

- 探索性数据分析，主题不明、多指标对比、业务汇报。
- 适合图表数量大（10–18 张），无明显头部表。

## 总体栅格

- **12 列** CSS Grid。
- 顶部条高 `100px`，主区按 3 行均分。
- 主区每行 4 列 (col 3fr)，单个图占 `3 × 1fr` 单元格。

## 槽位清单

| 槽位 ID        | 栅格坐标          | 必填字段                                  | 可选组件                |
|----------------|-------------------|-------------------------------------------|-------------------------|
| `header-0`     | col 1–4 / row 1   | `title`, `value`, `unit`                  | KPI 卡片                |
| `header-1`     | col 5–8 / row 1   | 同上                                      | KPI 卡片                |
| `header-2`     | col 9–12 / row 1  | 同上                                      | KPI 卡片                |
| `grid-0`       | col 1–3 / row 2   | `title`, `x_field`, `y_field`, `data`      | 柱状 / 折线             |
| `grid-1`       | col 4–6 / row 2   | 同上                                      | 饼图 / 环形             |
| `grid-2`       | col 7–9 / row 2   | 同上                                      | 面积 / 雷达             |
| `grid-3`       | col 10–12 / row 2 | 同上                                      | 漏斗 / 排行             |
| `grid-4`       | col 1–3 / row 3   | 同上                                      | 同上                    |
| `grid-5`       | col 4–6 / row 3   | 同上                                      | 同上                    |
| `grid-6`       | col 7–9 / row 3   | 同上                                      | 同上                    |
| `grid-7`       | col 10–12 / row 3  | 同上                                      | 同上                    |
| `grid-8`       | col 1–4 / row 4   | `columns[]`, `rows[][]`                   | 表格                    |
| `grid-9`       | col 5–8 / row 4   | `columns[]`, `rows[][]` 或 `text`         | 表格 / 洞察             |
| `grid-10`      | col 9–12 / row 4  | 同 `grid-9`                               | 表格 / 洞察             |

## 组件到槽位的映射规则

1. 顶部 KPI：把最重要的 3 个数字指标放 header。
2. 主图表：按 importance_score 降序依次填充 `grid-0..7`（最多 8 张）。
3. 剩余的表格/洞察落到 `grid-8..10`，按数据丰富度优先表格。

## 内容要求

- KPI 标题明确单位（百分比 / 金额 / 笔数）。
- 每个 `grid-*` 必须填图表，不得留空。
- 总组件数控制在 12–18。
