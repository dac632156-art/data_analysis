## 项目真实起源 / 动机（用户 2026-07-13 16:20 亲述，用于"为什么做"题）
- 痛点：学生/不懂分析的人想分析却不会写 prompt；以及一直做重复"清洗→画图→写结论"劳动。
- 主因：**上一段实习每周要交"周检"报告**（CV 模型全流程：SKU图片下载分类→剔低质→训练/测试集划分→分配+分担标注→标注质检→服务器训练[继承权重/设轮数/加新SKU]→转换部署→测试集预打标→人工质检→算precision/recall/F1→总F1>95%上线；**周检=对B端客户线上数据质检评估，模型整体>95%，单体SKU F1<95%做归因分析并输出报告**）。为减负自写本地demo把"清理规则+图表/报告写法"固化→平台初始形态。
- 为**省 token** 接 AI 接口起步用**阿里通义千问免费版**生成报告（注意：现代码接的是 DeepSeek，面试答"早期千问、平台化后支持多模型含 DeepSeek"）。
- 此起源已写进 `面试答辩准备_DataMind.md` 第二节（含真实实习全貌+周检 QC 细节），替换原 A/B/C 泛框架。问卷"实习细节(公司/岗位)"需用户自答。
