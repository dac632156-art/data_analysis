### 项目全貌（DataMind AI - 数据分析智能体）
- 三层架构：React/Vite/TS 前端 + FastAPI 后端 + Python 自研分析引擎(src/)
- AI 模型：DeepSeek（原生 openai SDK 直连，非 LangChain，关闭 SDK 重试防超时叠加）
- 部署：后端 Render（uvicorn），前端 Vercel（静态构建 SPA）

### 关键引擎（简历差异化亮点）
1. **分析知识中心(analysis_library)**：11 个 YAML 意图(growth/ranking/comparison/structure/concentration/distribution/correlation/anomaly/retention/proportion/geo)，registry 路由，加意图零代码
2. **分析模板+计算器(analysis_templates/calculators)**：纯数据契约，AnalysisPackage(findings:KPI/Chart/Table)
3. **推理管道(reasoning)**：RuleEngine→BusinessFactGraph→EvidenceEngine(STRONG/MODERATE/WEAK)→LLMReasoner，三段独立、可无 LLM 降级
4. **看板布局引擎(dashboard/layout_engine)**：BusinessGrouper→LayoutSelector(策略规则)→GridAllocator(12栅格/最大余数补满/视觉平衡)，纯规则不读 DataFrame
5. **AI Agent(ai_agent/agent)**：五阶段报告流水线(pandas精确统计→LLM洞察叙事)，多级降级 + 结构化 JSON 兜底解析

### 端到端链路
上传CSV → 数据清洗 → 列分类/意图识别 → 分析执行(Planner+AnalysisLibrary+模板) → 图表(ECharts)/看板(WidgetGenerator+LayoutEngine) → 推理洞察(ReasoningPipeline) → 报告生成(异步无状态+轮询)
