## 用户需求

数据量增大到约 3GB（百万级行）后，在分析可视化模块（AnalysisPage → 一键生成分析计划 → 执行分析 → /analysis/run）中，洞察结果生成的图表只显示一部分，无法完整渲染。

## 核心问题

图表数据未对大数据做降采样/聚合上限，导致 ECharts option 内含百万级数据点：

- 时间序列未重采样（growth.py prepare_series 仅 groupby 求和），高基数时间列产生数百万时间点；
- 散点/异常图直接用全量原始行（correlation_analysis.py、anomaly_analysis.py）；
- chart_renderer.py 渲染时无任何条数上限，巨型 option JSON 在传输/解析时被截断，或 ECharts 在固定高度画布上只能绘制一部分。

## 功能目标

1. 为所有图表类型建立统一的"数据点上限"护栏，确保 option 体积可控、图表完整呈现。
2. 对时间序列在聚合层做自动重采样，趋势图点数有界且语义合理。
3. 对原始行散点图做采样，避免构建超大 DataFrame 与 option。
4. 小数据（千行内）行为与结果完全不变。

## 技术栈

- 后端：Python + pandas + FastAPI（现有栈，沿用 src/analysis_templates、src/calculators、src/echart_generator 体系）
- 前端：React + ECharts（无需改动，仅确认当前 VisualizationRenderer / EChartView 链路正确）

## 实现方案

采用"统一下游护栏 + 关键上游降采样"双层策略，复用现有 `create_chart` 单一入口与 `prepare_series` 聚合逻辑，避免分散修改每个模板。

1. 统一护栏（核心，覆盖所有图表类型）
在 `src/echart_generator.py` 的 `create_chart()` 统一入口，对生成后的 `option` 调用新增的 `_cap_option_data(option)`：

- 定义常量 `_MAX_SERIES_POINTS = 2000`（折线/散点/柱状/面积等单序列点上限）、`_MAX_CATEGORY = 50`（类目轴上限）、`_MAX_PIE_SLICES = 20`。
- 类目轴（xAxis.data 存在）：按均匀采样得到保留下标，同步裁剪 xAxis.data 与每个 series.data，保证对齐不串行。
- 数值轴散点/气泡（series.data 为 [x,y,...] 数组）：对整个 points 数组均匀采样。
- 饼图/树图：按 value 取 Top N，并将剩余合并为"其他(合计)"扇区，避免丢值。
- 热力图（类目矩阵通常较小）：若任意轴类目超上限，按均匀采样两轴并过滤 data 中越界坐标。
由于所有图表均经 `create_chart` 分派，此护栏一次覆盖全量类型，彻底解决巨型 JSON 截断问题。

2. 上游时间序列重采样（趋势图专用，降计算与数据量）
在 `src/calculators/growth.py` 的 `prepare_series()` 中，groupby 之后若时间桶数量超过 `_MAX_SERIES_POINTS`，按时间粒度自动升阶重采样（秒→分→时→日→周→月→季→年），对 metric 求和，使趋势/增长/累计/移动平均四类图点数有界且更可读。

3. 原始行散点图采样（性能护栏）
`src/analysis_templates/correlation_analysis.py` 与 `anomaly_analysis.py` 中 `df[[...]].to_dict("records")` 改为先按上限采样（如 `df.sample(min(N, len))` 或按阈值均匀抽样），避免向 `chart_renderer` 传入百万行 DataFrame，减少内存与构建开销。

## 实现要点

- 采样必须"均匀"而非简单 head，避免趋势/分布失真（用 `np.linspace` 取整下标）。
- 类目轴裁剪须保证 xAxis.data 与所有 series.data 用同一组下标，否则图例会错位。
- 饼图"其他"扇区需累加被裁剪项 value，保证合计与占比正确。
- 仅在超过阈值时才采样，低于阈值原样返回，确保小数据零影响。
- `_cap_option_data` 放在 `create_chart` 返回前，不侵入各 `create_*_chart` 内部，降低回归风险。

```mermaid
  E --> F{growth 等是否重采样}

  H --> I
  I --> J[有界 ECharts option]

```
