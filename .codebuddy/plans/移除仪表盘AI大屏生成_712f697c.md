## 用户需求

删除仪表盘页面中的「AI 生成大屏」功能，包括前端 AI 按钮及处理函数、后端 `echart-ai-layout` 端点、前端 API 客户端中对应函数。看板框架已固定（9 个 section，每种 section 有确定图表类型），不需要 AI 来猜图表配置。

## 核心功能

- 移除 DashboardPage 中「AI 生成大屏」按钮（含"自动推荐"和"按描述生成"两个子按钮）
- 移除后端 AI 推荐大屏布局的 API 端点
- 移除前端 API 客户端中不再使用的函数
- 仪表盘其他功能完全保留：默认图表加载、已保存图表加载、模板切换、PNG/HTML 导出、AI 分析报告生成

## 技术方案

### 实现策略

纯删除操作，不新增任何代码。按**后端 → API 客户端 → 前端页面**的顺序逐一移除，保证依赖关系正确。

### 需要删除的内容

#### 1. 后端 `backend/routers/dashboard.py`

删除 `api_echart_ai_layout` 函数（第 411 行路由装饰器至第 548 行函数结尾），约 138 行。注意 `_normalize_map_configs` 函数保留（第 21 行，仍被 `api_dashboard_echarts` 第 172 行使用）。

#### 2. 前端 API 客户端 `frontend/src/api/client.ts`

删除 `getEChartsAiLayout` 函数（第 296-310 行）。保留 `getDashboardRecommend`、`getAiLayout`（未被调用，但按用户要求不删除）。

#### 3. 前端页面 `frontend/src/pages/DashboardPage.tsx`（共 8 处改动）

- 第 4 行：从 `react-icons/fi` 导入中移除 `FiZap`
- 第 67-68 行：删除 `aiReason`、`aiTitle` 状态
- 第 73-77 行：删除 `aiLoading`、`aiQuery`、`showAiPanel` 状态
- 第 124 行：删除 `getProviderConfig` 函数
- 第 126-146 行：删除 `handleAiLayout` 函数
- 第 148-170 行：删除 `handleAiCustomLayout` 函数
- 第 342-344 行：`displayTitle` 去掉 `aiTitle` 引用
- 第 378-379 行：删除 `aiReason` 显示；第 384-417 行：删除 AI 按钮下拉面板

### 不影响的功能

- 分析页的 AI 洞察、AI 对话、AI 数据计算
- 报告生成中的 AI 五阶段分析
- 默认图表加载、已保存图表加载
- 模板切换、PNG/HTML 导出
- `_normalize_map_configs` 函数
