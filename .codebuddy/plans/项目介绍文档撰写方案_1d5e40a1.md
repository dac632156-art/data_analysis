## 用户需求

用户要求彻底阅读整个「DataMind AI 数据分析智能体」项目，并在项目文件中写入一份项目介绍文档，内容必须同时涵盖**项目业务**与**技术架构**两大部分，作为项目的整体说明文档。

## 文档内容要求

- **业务部分**：说明产品定位（DataMind AI 是什么、解决什么痛点）、目标用户与典型使用场景、核心业务流程（上传数据 → 智能清洗 → 分析与洞察 → 可视化驾驶舱 → AI 报告），以及四大功能模块（数据上传、智能清洗、分析可视化、数据看板/报告）的能力概述与用户价值。
- **架构部分**：说明整体技术栈与分层（React+TS 前端 / FastAPI 后端 / Python 核心分析引擎 src）；核心模块职责（AnalysisLibrary 分析知识库、Planner 调度器、analysis_templates 分析模板、reasoning 推理管道、dashboard 自动驾驶舱、ai_agent Agent、echart 渲染）；关键数据流（会话内 DataFrame → AnalysisPackage → ECharts/驾驶舱 Schema）；部署架构（Vercel 托管前端 + Render 托管后端 API，异步报告规避超时）；目录结构概览；工程实践（AI 多服务商 OpenAI 兼容接入、双层数据防护、降级策略）。
- **产出物**：在项目根目录新建独立中文文档 `项目介绍.md`（不覆盖任何现有文件），语言为简体中文，结构清晰、含必要的小标题与一张系统架构图（mermaid）。
