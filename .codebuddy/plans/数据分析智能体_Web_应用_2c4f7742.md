## 产品概述

DataMind AI 数据分析智能平台 — 前后端分离架构的数据分析与可视化平台。React SPA 前端 + FastAPI Python 后端，集成 LangChain + DeepSeek AI Agent，支持数据上传、清洗、智能分析、大屏仪表盘和报告导出。

## 核心功能

- **数据上传**：支持 CSV/Excel/JSON/SQLite 文件上传（react-dropzone 拖拽），上传后展示数据预览和字段信息
- **AI 数据清洗**：自动识别并处理缺失值、数据类型修正、异常值检测，用户确认或调整清洗方案
- **统计分析**：描述性统计（均值/中位数/标准差等）、分组对比分析、相关性分析
- **智能绘图**：支持柱状图、折线图、散点图、饼图、直方图、箱线图、热力图、词云、地图等多种图表，AI 自动推荐图表类型
- **大屏仪表盘**：4 种模板（指挥中心 / 数据看板 / 经典网格 / 分析报告），AI 自动推荐布局，支持导出 HTML/PNG
- **AI 对话分析**：AI 自动生成数据洞察；用户自然语言提问，AI 调用 Python 代码分析回答
- **分析报告**：AI 生成图文分析报告，导出为可交互 HTML 文件

## Architecture

前后端分离架构，CORS 跨域通信：

```
React Frontend (localhost:5173)  <-->  FastAPI Backend (localhost:8000)
     Vite Dev Server                    Uvicorn ASGI
     React Router v7                    9 组 REST API (/api/*)
     Axios HTTP Client                  SessionManager（内存会话隔离）
     ECharts 可视化                      Pandas 数据处理引擎
     TailwindCSS 样式                    LangChain + DeepSeek AI Agent
```

### API 路由

| 路径 | 功能 | 对应后端模块 |
|------|------|-------------|
| `/api/upload` | 文件上传 | data_loader.py |
| `/api/data/*` | 数据预览/列信息 | data_loader.py |
| `/api/clean/*` | 数据清洗 | data_cleaner.py |
| `/api/stats/*` | 统计分析 | stats_analyzer.py |
| `/api/chart/*` | 图表生成 | echart_generator.py |
| `/api/dashboard/*` | 仪表盘 KPI + ECharts | dashboard_builder.py |
| `/api/insights/*` | AI 自动洞察 | ai_agent/agent.py |
| `/api/chat/*` | AI 对话分析 | ai_agent/agent.py |
| `/api/report/*` | 报告生成 | report_generator.py |

### Data Flow

```
上传文件 → FormData → FastAPI → data_loader → DataFrame (存入 session)
清洗数据 → JSON参数 → FastAPI → data_cleaner → 返回清洗结果 JSON
生成图表 → JSON参数 → FastAPI → echart_generator → 返回 ECharts option JSON → ECharts 渲染
仪表盘 → session_id → FastAPI → dashboard_builder → KPI JSON + ECharts JSON → 大屏渲染
AI 对话 → 问题+API Key → FastAPI → ai_agent (LangChain + DeepSeek) → 返回洞察/分析文字
导出报告 → 前端组装 → generateEChartsDashboardHTML() → 独立 HTML 文件下载
```

### Key Technical Decisions

1. **ECharts 渲染方案**：后端 echart_generator.py 生成 ECharts option JSON，前端 ECharts 模块化导入（echarts/core）按需注册组件渲染，支持 2D/3D 地图、词云等高级图表类型。

2. **会话管理**：FastAPI 后端 UUID 生成 session_id，DataFrame 存内存字典，前端 localStorage 持久化 session_id。

3. **大屏模板系统**：4 种可切换模板（指挥中心 / 数据看板 / 经典网格 / 分析报告），AI 可自动推荐最优布局组合。

4. **AI 集成**：LangChain 工具链 + DeepSeek 模型，支持自动洞察生成、自然语言数据分析、大屏布局推荐。

5. **导出能力**：html2canvas 截图 PNG；generateEChartsDashboardHTML() 生成可独立运行的 HTML 文件（内嵌 ECharts CDN）。

6. **星云主题**：TailwindCSS 自定义深蓝紫色渐变 + glassmorphism 玻璃态设计，CSS 动画模拟星云效果。

## 页面规划（共 4 个核心视图）

### 页面 1：数据上传与预览（UploadPage）

- 拖拽上传区（react-dropzone），虚线边框 + 星云动画
- 数据概览卡片：行数、列数、缺失值数量
- 数据表格预览（前 100 行）
- 字段信息面板：每列名、类型、缺失值数、唯一值数

### 页面 2：数据清洗（CleanPage）

- AI 清洗建议卡片，每个问题可"应用"或"忽略"
- 手动清洗面板：缺失值处理 / 类型修正 / 异值检测
- 清洗前后对比统计

### 页面 3：分析可视化（AnalysisPage）

- Tab 切换：统计分析 / 智能绘图 / AI 对话
- 统计分析：描述性统计表格 + 相关性矩阵
- 智能绘图：ECharts 交互式图表，支持保存到仪表盘
- AI 对话：自然语言提问 + AI 分析回答

### 页面 4：仪表盘大屏（DashboardPage）

- 4 种模板切换：指挥中心 / 数据看板 / 经典网格 / 分析报告
- AI 自动推荐布局（DeepSeek 分析数据后推荐图表组合）
- AI 自然语言定制（描述想要的布局，AI 自动配置）
- 导出能力：PNG 截图（html2canvas）/ 独立 HTML 文件（内嵌 ECharts CDN）
- 分析报告：AI 生成图文报告 + 结论建议
