**问题描述**
用户期望词云图「每个文字的颜色和大小都不一样」，但实际渲染出全黑、字号一致的 4 个词（电子产品/服饰/日用品/食品）。这是 Galaxy AI Analytics 数据分析项目里"分析"模块的词云图（基于 `echarts-wordcloud` 扩展）渲染问题，属于"数据看板/仪表盘"范畴。

**视觉期望**

- 字体大小按"出现次数"比例分布（频次高的词大、靠中心；频次低的词小、散外圈）
- 颜色沿用 VDS 10 色有序分类色板（星光蓝 #38BDF8 / 靛蓝 / 极光青 / 金 / 玫瑰粉 / 珊瑚橙 / 青柠绿 / 淡紫 / 天空蓝 / 湖水绿）
- 形状自然分布（circle 形态），词与词之间留有间距和角度旋转

**根因（已 100% 锁定）**

链路：`wordcloud_analysis.build_charts` → `ChartRenderer.render` → `create_wordcloud`

1. **`build_charts` 输出的 value 全是 1**

- 实际只是统计各类别出现次数（`value_counts`），但写成了 `cloud_data.append({"x": name, "y": value})`（`src/analysis_templates/wordcloud_analysis.py:119`）
- 经 `ChartRenderer.render` 的 `rename_map` 把 "x"/"y" 改成真实列名（产品类别/count）后，喂进 `create_wordcloud` 的 df 是 4 行 `[{产品类别: 电子, count: 44}, ...]`
- 而 `create_wordcloud` 内部又做了一次 `df[text_col].value_counts().head(50)`（`src/echart_generator.py:732`）
- 4 行全不同 → value_counts 后每行还是 1 → **所有词 value=1** → ECharts 词云按 value 比例算 fontSize → **全一样大**

2. **颜色 function 看似"没生效"**

- color function 字符串是合法 JS（已用 node 验证，ASCII-only），4 个词在 10 色板里索引应不同
- 但用户看到全黑，最可能是 `create_wordcloud` 的 series.data 因为 value=1 让 ECharts 走了某种"全部同色降级"路径
- 修复 value=1 链路后颜色会自然出现

**修复策略**（最小改动、沿用现有架构）

A. `wordcloud_analysis.build_charts`：把 `{"x": name, "y": value}` 改成 `{"name": name, "value": value}`（消除"占位键"依赖，直接给 ECharts 期望的格式）。`ChartRenderer.render` 的 `rename_map` 在 wordcloud 场景下会因 "x"→"name"、"y"→"value" 找不到 ChartData.x/y 真实列而跳过重命名（无副作用），df 直接用。

B. `create_wordcloud` 增强：支持**两种输入模式**：

- **已聚合模式**（df 已是 `[{name, value}, ...]`）：直接 `df.to_dict("records")` 当 cloud_data
- **明细模式**（df 仍按 x/y 走原逻辑）：保留原 `value_counts` 路径
- 判定：df 有 `name` 列 → 已聚合；否则明细

C. 验证：用 `[{产品类别: 电子产品, count: 44}, ...]` 输入，确认 output 的 `series.data` 是 `[{name: 电子产品, value: 44}, ...]`，value range 是 12~44。

**影响范围**

- 仅 2 个文件：`src/echart_generator.py:715-784`、`src/analysis_templates/wordcloud_analysis.py:108-125`
- `src/chart_renderer.py` 无需改动（rename_map 对 wordcloud 走"无 key"分支，安全跳过）
- `frontend/src/components/EChartView.tsx` 无需改动（已正确处理 wordCloud 类型）
- 风险：仅影响 wordcloud 一种图表；其他图表的 `{"x", "y"}` 占位键保持不变

**验证方式**

- Python 单元：构造 4 行 [{name, value: 12~44}] 输入，断言 series.data 第二列范围 > 0
- 端到端：重启后端，刷新浏览器，重新触发"产品类别词云"分析
