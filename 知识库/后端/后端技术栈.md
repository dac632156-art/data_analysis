## 一、一句话技术栈

**Python + FastAPI + uvicorn + pandas/numpy**，LLM 走 OpenAI SDK 接 DeepSeek，无数据库（内存会话），部署到 Render。

| 层面 | 技术选型 | 对应笔记 |
|---|---|---|
| Web 框架 | FastAPI | [[FastAPI详解]] |
| ASGI 服务器 | uvicorn | [[uvicorn是什么]] |
| 路由组织 | APIRouter（10 个模块） | [[路由是什么]] |
| 接口设计风格 | RESTful | [[RESTful API是什么]] |
| 接口文档 | Swagger `/docs`（自动生成） | [[Swagger文档是什么]] |
| 数据处理 | pandas / numpy（全内存） | —— |
| LLM 接入 | OpenAI Python SDK → DeepSeek | [[API调用是什么]] |
| 部署 | Render（Procfile + runtime.txt） | [[uvicorn是什么]] |

## 三、后端分层架构

后端整体分四层，从上到下职责递减、通用性递增。

| 层级 | 目录 / 文件 | 职责 |
|---|---|---|
| ① 接入层 | `backend/main.py`、`backend/routers/`、`backend/services/` | app 装配、路由注册、CORS、全局异常、SPA 托管；内存会话管理 |

> 应用与服务器之间的通信规范见 [[ASGI是什么]]；真正运行应用的服务器见 [[uvicorn是什么]]。
| ② 业务编排层 | `src/` 顶层（planner、chart_renderer、report_analyzer、column_classifier） | 调度、列识别、图表渲染、报告编排 |
| ③ 知识/模板/计算层 | `src/analysis_library/`、`analysis_templates/`、`calculators/`、`domain/` | YAML 声明分析能力、统一产出 AnalysisPackage、纯指标计算、业务发现模型 |
| ④ 智能层 | `src/ai_agent/`、`src/reasoning/`、`src/dashboard/` | LLM 对话 / 报告 / 推理 / 看板自动生成 |

> 详细展开见 [[项目架构全景图]]。

## 四、一次请求的完整链路（谁接谁）

```
浏览器  →  uvicorn（ASGI 服务器，监听端口）      ← [[uvicorn是什么]]
        →  FastAPI app（路由匹配 + Pydantic 校验） ← [[FastAPI详解]]
        →  APIRouter（10 个业务模块之一）          ← [[路由是什么]]
        →  处理函数（调 src/ 业务逻辑）
        →  return dict → FastAPI 序列化 JSON
        →  uvicorn 回写 HTTP 响应 → 浏览器
```

> 若后端需要调用大模型，会在处理函数内经 OpenAI SDK 发第二层请求给 DeepSeek，详见 [[API调用是什么]]。

## 五、10 个 APIRouter 一览

| Router | 职责 |
|---|---|
| upload | 上传闸门 / 排队 |
| data | 预览 / 列信息 / 下载 / 计算 |
| clean | 缺失 / 类型 / 异常 / 去重 / AI 清洗 |
| stats | 描述统计 / 分组 / 相关性 |
| chart | ECharts 图表生成 |
| dashboard | KPI / 图表 / 收藏 / 标题命名 |
| insights | AI 洞察 |
| report | AI 报告异步任务 |
| analysis | 分析执行与保存 |
| reasoning | 业务推理 |

> 路由如何从「定义」到「挂载」再到「可访问」，见 [[路由是什么]] 与 [[FastAPI详解]] 的完整闭环。
