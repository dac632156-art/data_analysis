# 代码即文档（FastAPI）

## 字面含义

**API 代码本身 = 接口文档的来源**，不需要另写文档文件。FastAPI 读懂代码，渲染成 Swagger（`/docs`）。代码和文档是同一份东西。

## 对比传统做法

| 做法 | 文档来源 | 问题 |
|---|---|---|
| 传统（Flask + 手写文档） | 额外写 Markdown / Postman | 代码改了文档忘改，对不上 |
| FastAPI（代码即文档） | 代码本身 | 改代码 = 改文档，永不脱节 |

传统是"两份真相"（迟早分歧）；FastAPI 是"单一真相"。

## 代码逐行对应文档（项目实例）

```python
# backend/routers/clean.py
@router.post("/clean/missing-report")
async def api_missing_report(req: SessionRequest):
    """缺失值检测报告"""
    ...
```

```python
class SessionRequest(BaseModel):
    session_id: str
    include_charts: bool = True
```

| 代码 | → 文档显示 |
|---|---|
| `@router.post("/clean/missing-report")` | 路径 + 方法：`POST /clean/missing-report` |
| `session_id: str` | 参数 session_id（string，必填） |
| `include_charts: bool = True` | 参数 include_charts（boolean，可选，默认 true） |
| `"""缺失值检测报告"""` | 接口文字说明 |
| `return {...}` | 响应结构描述 |

## 核心好处

1. **单一事实来源**：代码改 → 文档自动改
2. **零额外维护**：不用专门写文档
3. **强制类型清晰**：不写类型注解 = 没有文档，反向逼清接口定义

## 一句话

**代码即文档 = FastAPI 把路由、类型注解、Pydantic 模型、docstring 当作文档用，代码是唯一真相，文档是它的自动投影。**
