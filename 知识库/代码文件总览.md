## 一、后端层 `backend/`（FastAPI 入口 + 路由器 + 会话管理）

### 1.1 应用入口

| 文件（相对 `backend/`） | 职责 |
|---|---|
| `main.py` | FastAPI 应用创建：配置 CORS、注册 10 个 `/api` 路由前缀、托管前端静态文件、健康检查 `/api/health`、会话创建 `/api/session/new` |

### 1.2 路由层 `routers/`（10 模块）

| 文件 | 职责 |
|---|---|
| `routers/upload.py` | 文件上传路由：预约插槽闸门、排队查询/取消、释放插槽、CSV/Excel/JSON/SQLite 文件解析 |
| `routers/data.py` | 数据操作路由：预览、基本信息、列分类、摘要、AI 计算新列、同环比计算、CSV 下载 |
| `routers/clean.py` | 数据清洗路由：缺失值报告/处理、类型检测/转换、异常值检测/处理、去重、清洗历史/对比、AI 智能清洗 |
| `routers/stats.py` | 统计分析路由：描述性统计、分组统计、相关性矩阵、快速洞察 |
| `routers/chart.py` | 图表生成路由：调用 echart_generator 创建 ECharts option |
| `routers/dashboard.py` | 仪表盘路由：KPI 计算、ECharts 图表/收藏、分析包读取、Dashboard Schema 生成、AI 智能命名、Card 生成 |
| `routers/insights.py` | AI 洞察路由：AI 生成洞察（含三层 intents 解析兜底）、纯规则兜底默认意图、AI 对话分析 |
| `routers/analysis.py` | 分析执行路由：Planner 翻译 → 模板执行（递归降级/fallback）→ ChartRenderer 渲染 → 缓存 |
| `routers/report.py` | 报告生成路由（异步）：提交 LLM 报告任务返回 task_id，前端轮询；信号量限流并发 |
| `routers/reasoning.py` | 业务推理路由：基于 AnalysisPackage 运行推理管道，返回根因/风险/机会/摘要 |

### 1.3 服务层 `services/`

| 文件 | 职责 |
|---|---|
| `services/session_manager.py` | 会话管理器（**全局内存单例**）：UUID 会话 ID、最多 5 并发数据插槽、预约/排队/晋升模式限流、DataFrame 内存 + pickle 落盘双保险、撤销栈、分析包缓存、后台线程定期清理过期会话 |

### 1.4 工具层 `utils/`

| 文件 | 职责 |
|---|---|
| `utils/ai_error.py` | AI API 错误增强：将 OpenAI 兼容 API 的异常转为中文用户引导（model_not_found/401/403/超时） |

### 4.1 跨层依赖关系

```
用户浏览器
  ↓
前端 React 4 页面（pages/） + 组件（components/）
  ↓ axios /api/*
后端 API 路由（routers/） ← 会话管理（services/session_manager.py）
  ↓
引擎层（src/）
  ├─ data_loader / column_classifier / data_cleaner（数据预处理）
  ├─ planner / analysis_library / analysis_templates（规划→执行）
  ├─ echart_generator / chart_renderer（图表生成）
  ├─ kpi/table/insight/conclusion/card 渲染器（output 打包）
  ├─ dashboard/（大屏布局引擎）
  ├─ report_analyzer / report_builder（报表）
  ├─ ai_agent（LLM 推理）
  └─ reasoning/calculators/domain（进阶推理）
```

### 4.2 关键设计原则

- **AI 只动嘴，引擎只算数**：`ai_agent/` 只在洞察、报告、对话 4 处出现；上传/清洗/匹配/算数/画图/布局全是确定性引擎。
- **处处有兜底**：Planner 的缺失列派生 + fallback 链、insights 的三层 JSON 解析防御、报告 `_build_fallback_from_packages`。
- **JSON 安全层**（`src/utils/json_serializer.py`）：所有 API 返回前必过 `sanitize_json()`。
- **VDS 配色统一 SSOT**：前端 `theme/Palette.ts` 唯一持有 HEX 色 → ChartStyle/SemanticColor/Shadow → 后端 `echart_generator.py` 的 BLUE_PALETTE/WARM_COLORS 镜像。
- **Color in the node**: 前端是"操作台"，后端是"调度员"，引擎核心是"干活的工人"，AI 是"写文案的参谋"，内存是"临时工作台"。
