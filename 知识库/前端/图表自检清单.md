# 图表自检清单（让图一眼看懂）

> 做任意一张分析图，**交付前**用这份清单过一遍。5 条全过，图基本就能"一眼看懂"；卡住哪条，图就会让人发懵。
> 缘起：用户用"转化漏斗测试数据"生成「渠道转化率对比」图，发现数据没错，但**外人看一眼完全抓不到重点**——于是沉淀出这套硬指标。

## 5 条自检（必过）

1. **标题说清了"比什么 + 单位"吗？**
   - ❌ "渠道转化质量对比"（"质量"误导成综合打分，且没单位）
   - ✅ "各渠道转化率对比（%）"（比什么 + 单位一目了然）

2. **每个数据点有数字标注吗？**（别只靠柱高猜）
   - 柱状/条状图每根柱子顶部标数值，如 `4.0%`；折线图关键拐点标值。
   - 只给坐标轴刻度、不标数据点，看图的人得拿尺子量——不合格。

3. **最好 / 最差 / 异常值被高亮了吗？**
   - 最高项、最低项、离群项要用颜色 / 描边 / 标注突出。
   - 让结论"自己跳出来"，而不是让人自己找。

4. **有"一句话结论"吗？**
   - 图下方必须有一句把数据翻译成建议的话。
   - 例：「小红书转化率最高(4.0%)，抖音为 0；建议资源向小红书倾斜」。
   - 没有结论的图 = 只是"把数据摆出来"，不是"把结论讲出来"。

5. **百分比和个数、自己分母和总分母，混没混？**
   - 百分比（小红书占 4%）≠ 转化率（小红书自己访客里 4% 下单）≠ 转化个数（小红书带来 4 单）——三者口径完全不同，加总逻辑也不同：
     - 流量占比、各渠道转化数占总转化 → 加起来 = 100%
     - **转化率（每个渠道分母=自己流量）→ 加起来 ≠ 100%**（这是正常的，不是数据错）
   - 轴上必须标清是 `%` 还是个数；"转化率"图尤其要在标题/副标题点明分母是"各渠道自身流量"。

## 反面教材（真实踩坑）

「渠道转化率对比」原图问题清单：

| 现在的问题 | 应该长这样 |
|---|---|
| 标题"渠道转化质量对比" | 标题"各渠道转化率对比（%）" |
| 横轴只写"转化" | 横轴"转化率 (%)"，柱顶标 `4.0%` |
| 没结论 | 图下一句："小红书最高(4.0%)，抖音为0；建议倾斜投放" |
| 抖音 0% 不知真假 | 标注"抖音：无转化数据 / 数据缺失"，避免误读成真 0 |
| 没有基准线 | 加一条行业平均线（如 2.5%），一眼看出谁高于/低于平均 |
| 右下角"转1"乱码 | "转化率"三字被截断/编码错，须修 |

> 注：该图右下角出现的"转1"是"转化率"被截断/编码错误所致，属显示 bug，与口径问题并列修复。

## 一句话心法

> **好的分析图 = 标题带单位 + 数据点有数 + 极值被高亮 + 一句结论 + 口径不混。**
> 缺任意一条，就是"给内行看的数据"，不是"给任何人一眼看懂的图"。
